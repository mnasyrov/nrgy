# Contributing

## Назначение

Этот раздел объясняет, как вносить изменения в репозиторий Nrgy.js. Здесь
собраны правила репозитория по документации, кодстайлу, рабочему процессу и
автоматизированным участникам.

## Кому это читать

- контрибьюторам, меняющим исходный код, тесты или документацию;
- авторам пакетов внутри монорепозитория;
- автоматизациям и AI-агентам, генерирующим документацию или кодовые правки.

## Состав раздела

- [../../AGENTS.ru.md](../../AGENTS.ru.md): onepager и точка входа для
  AI-агентов.
- [Требования к документации](./docs_requirements.ru.md): обязательные правила
  структуры и размещения документации модулей и пакетов, а также шаблон
  prompt'а для агентов-генераторов документации.
- [Стиль кодирования](./coding_style.ru.md): паттерны конкретно этого проекта
  (Atom, Effect, Scope, Controller) с примерами кода.
- [Процесс разработки](./development_workflow.ru.md): повседневные команды,
  структура репозитория и работа с сайтом.
- [Релизный процесс](./release_workflow.ru.md): версионирование, публикация и
  релизные проверки.

## Примечания

Полный список правил — в
[docs_requirements.ru.md](./docs_requirements.ru.md). Держите `.md` и `.ru.md`
документы синхронизированными.
